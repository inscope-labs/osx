# Pure-Kotlin Multiplatform Shared Domain Module

This folder is configured for future multiplatform extraction (KMP). It houses platform-agnostic models and validators for:
- **CNS-1:** Foundation & Invariants
- **CNS-2:** Key Hierarchy & Confirmation Policies
- **CNS-3:** Envelope Interface & Serializers
- **CNS-4:** Session State Automata
- **CNS-5:** Runtimes & Pre-Authorization Rules
- **CNS-6:** State Validation Rules
- **CNS-7:** Operational Profile Definitions
